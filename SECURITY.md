# Security Policy

## Supported versions

jotaro is pre-1.0. Only the latest release receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

Report it privately through GitHub: **Security → Report a vulnerability** on this repository
(<https://github.com/RIRUa/jotaro/security/advisories/new>).

Include what you found, how to reproduce it and the version you used. You can expect an initial reply within about a week.

## Scope

jotaro is a load-testing tool: pointing it at a server you do not own or have permission to test is your responsibility. Reports about that use are out of scope.
